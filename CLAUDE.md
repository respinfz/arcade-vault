## Architecture

- **App Router** (`app/`): `app/layout.tsx` defines the root layout (Geist/Geist Mono fonts via `next/font/google`, global styles from `app/globals.css`); `app/page.tsx` is the (currently default) home page.
- **Path alias**: `@/*` maps to the repo root (`tsconfig.json`).
- **Styling**: Tailwind CSS v4 via `@tailwindcss/postcss` (see `postcss.config.mjs`); no `tailwind.config.*` file is needed under v4's CSS-first config.
- **Route typing**: `app/layout.tsx` uses generated route param types (e.g. `LayoutProps<"/">`), which come from `.next/types/` — regenerated by `next dev`/`next build`. Follow this typed-route pattern for new pages/layouts rather than hand-writing prop types.
